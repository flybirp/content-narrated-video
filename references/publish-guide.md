# 发布模块：视频做完后，发到自媒体平台还缺的资产

制作层管到 `final_<概要>_<时间戳>.mp4`（成片）为止。**发布层**是另一套资产，缺了它们视频发不出去、或发出去没流量。本模块覆盖发布层全流程：从「资产准备」到「发出去」到「发完复盘」。

## 总览：一条成片 → 多平台分发

核心资产只写一次（标题/标签/简介/封面），平台差异单独列（分辨率/标题长度/合规口径）。流程：

```
final_<概要>_<时间戳>.mp4（横版 16:9，成片名带「概要+时间戳」，多期不覆盖）
   ├─ 封面（gen_cover.py 横版 + 竖版）
   ├─ 标题/标签/简介（LLM 出 3 候选 + 平台差异化）
   ├─ 合规自查（checklist）
   └─ 分发：先发主平台 → 重渲竖版 → 发短视频平台 → 复盘
```

## 资产清单（6 项）

| # | 资产 | 产出方式 | 自动/人工 |
|---|---|---|---|
| 1 | 标题 | LLM 写（钩子 + SEO 关键词） | 自动出 3 候选 |
| 2 | 自选标签 | LLM 选（**查平台真实话题**，不自创） | 自动，需 WebSearch 验证热度 |
| 3 | 简介文案 | LLM 写（钩子 + 摘要 + 互动 + 话题 + 免责） | 自动 |
| 4 | 封面图 | `gen_cover.py` 纯设计型（AI 自选最吸引人标题 + 大字标题，数字锤可选） | 自动 |
| 5 | 分平台格式 | 改渲染参数（竖版 9:16 / 横版 16:9） | 半自动 |
| 6 | 合规免责 | 固定模板（财经必加） | 自动 |

## 1. 标题

**公式**：`[钩子] + [内容主体] + [悬念/数字]`

钩子类型（按内容选一个）：
- 数字钩子：`从 199 跌到 93`（涨跌幅度天然抓眼球）
- 悬念钩子：`能不能抄底` / `是不是陷阱`
- 反常识钩子：`越跌越买？`
- 身份钩子：`持有爱美客的人注意` / `给散户的 XX`（精准圈定目标人群）
- 结果钩子：`结果它跌了 70%`（先抛结果再讲过程）

出 **3 个候选**（不同钩子方向），让用户挑。

> **研究数据加成（详见 `references/viral-script.md` §6）**：标题最优长度 **11 词 / 65 字符**（BuzzSumo 1 亿标题研究）；**负向超级词 CTR 比正向高 63%**（Outbrain，如「三个习惯正在毁掉你的复购率」＞「三个习惯提升复购率」）；**具体数字碾压模糊**（「省 1247 元」＞「省 1000 元」、「跌 70%」＞「大跌」）；好奇心缺口（「[群体] 不会告诉你的 [话题]」）+ 反常识 / 预测句式转化更高。右上角数字钩子不是默认首选（见 §4 封面标题怎么选）。

### 多平台标题差异化（同一内容，三种写法）

标题不要一份到处发——各平台信息流展示规则不同：

| 平台 | 字数上限 | 展示特点 | 写法 |
|---|---|---|---|
| 抖音 | 55 字（前 15 字是钩子） | 信息流只显示前 15 字 + 封面 | 钩子前置、口语化、情绪化 |
| B站 | 80 字 | 标题完整显示 | 可长、信息量大、允许冒号式两段 |
| 小红书 | 20 字 | 标题短，配图是主视觉 | 种草语气、强调结果/价值 |
| 视频号 | ~40 字 | 用户偏成熟 | 语气收敛、少网络热梗 |

示例（爱美客同一内容）：
- **抖音**：`跌70%的医美龙头能抄底吗？账上65.7亿现金，市盈率25.8倍`
- **B站**：`爱美客从199跌到93：黄金坑还是价值陷阱？4分钟拆透四档建仓法`
- **小红书**：`医美茅跌到93块了，还要不要等？`

## 2. 标签

**核心规则：标签必须是平台真实存在、有人用的热门话题，不是自创词。** 发之前用 WebSearch 查目标平台的标签热度。

数量：抖音 5–10、B站 最多 12（10 tag + 分区）、小红书 8–10、视频号 3–5。

搭配策略：**大热门带曝光 + 小热门带精准**。
- 大热门（泛流量）：`#财经` `#股票` `#投资`
- 小热门（精准流量）：`#爱美客` `#医美` `#价值投资`

蹭热点：当日热点事件/板块相关就蹭（借势流量），不相关别硬蹭（会被判低质）。

**标签栏 vs 简介话题**：标签栏偏「分类性」（帮平台分发），简介里的话题偏「钩子性」（诱导点击），可以不完全一样。

财经类常用标签库（兜底，仍需按平台验证）：
`#财经` `#A股` `#股票` `#投资` `#价值投资` `#理财` `#基金` + 个股/行业专属词（如 `#爱美客` `#医美` `#白酒`）

## 3. 简介文案

结构（前 20 字定生死）：

```
[钩子一句] [内容摘要 1-2 句] [互动引导] [话题标签] [免责声明]
```

- 钩子：和标题呼应，但换句话，别重复标题
- 互动引导：`你怎么看，评论区聊聊` / `觉得有用点个赞`
- 免责（财经必加）：`以上为情景推演，不构成投资建议`

各平台差异：
- 抖音：简介短，把「结论 + 引导」放最前
- B站：可以写长简介（背景 + 时间戳目录），方便搜索
- 小红书：简介里多塞话题标签（小红书靠标签分发）

## 4. 封面图

用 `scripts/gen_cover.py`（**纯设计型，不抽帧**）：

```bash
python scripts/gen_cover.py \
    --title "传统资产正在被重定价" \
    --metric "8万亿" --unit "元" \
    --sub "× 算力底座光纤化 · 中美五个产业信号" \
    --size 1280x720 --accent gold \
    --slug "传统资产重定价-算力光纤化"
```

参数：`--title`（大字标题，必填）/ `--metric --unit`（核心数字视觉锤，**可选**，如「8 万亿 元」；见下「标题怎么选」）/ `--sub`（数据行副标题）/ `--size`（`1280x720` 横版 或 `1080x1920` 竖版）/ `--accent`（`gold` 默认 / `red` 涨 / `green` 跌）/ `--slug`（内容概要，文件名自动拼 `cover_横版_16x9|cover_竖版_9x16_<概要>_<时间戳>.png`，也可用 `--out` 覆盖）。

### 封面标题怎么选（先选标题，再决定要不要数字锤）

**封面 `--title` 不要默认挑「带数字的标题」。** 正确做法：

1. 看 `publish.json` 的 `titles` 候选（3 个钩子方向：数字 / 悬念 / 反常识 / 身份 / 结果 等）。
2. **AI 自行判断：按目标平台信息流、受众、内容调性，哪个候选最吸引人，就用哪个**做封面 `--title`。
3. 数字只是钩子之一——悬念、反常识、身份、结果类标题常常比「数字标题」更抓人，**不要因为某条带数字就优先选它**。
4. 选定后：
   - 若所选标题本身含强数字（跌幅 / 金额 / 倍数），才传 `--metric --unit` 做视觉锤；
   - 若所选标题是悬念 / 反常识类（不含数字或数字非重点），**不硬塞 `--metric`**，用大字标题本身抓眼球即可。

> 反例（旧习惯，禁止）：不管内容如何，一律把「数字钩子」那版当封面标题、硬塞一个大数字。
> 正例：测评类用「越跌越买？」、身份类用「持有 XX 的人注意」——这些不带大数字，但点击率可能更高。

### 封面设计原则

1. **视觉锤可选**：所选标题带强数字时，超大数字（价格/跌幅/金额）是最好用的视觉锤；所选标题不带数字时，用 3–8 个大字短句本身抓眼球，**别为了「有数字」硬编一个**。
2. **大字短句**：封面上的字要更短更狠（3–8 个大字），别把完整标题全搬上去。
3. **对比色**：深色底 + 高亮强调色（财经涨红跌绿），信息流里一眼跳出来。
4. **封面标题 ≠ 视频标题**：封面只放「钩子核心」，完整句放标题栏。
5. **数字协调一致**：封面上的数字（93 元 / 跌幅 70%）必须和标题、简介、口播画面里的数字**完全一致**——这是制作层「稿子里出现数字，画面同期显示同一个数字」原则在发布层的延伸。数字对不上会显得不专业，评论区必被挑错。

> **研究数据加成（详见 `references/viral-script.md` §7）**：封面带**人脸 CTR +35~50%**（短视频真人出镜见 SKILL.md「低配版真人出镜」）；画面**≤3 个元素**最跳（「限制你的兰博基尼」）；**高对比**配色暗色模式也跳；文字 **3–4 词**粗无衬线；用户平均 **1.8 秒**做决策，缩到 **120px 宽**仍能看清大字才算过关。

### 尺寸 + 安全区

| 平台 | 尺寸 | 比例 |
|---|---|---|
| B站 / 西瓜 | 1280×720 | 16:9 |
| 抖音 / 视频号 / 小红书 | 1080×1920 | 9:16 |

安全区（避免被平台 UI 遮挡，以实际平台为准）：
- 抖音封面：顶部约 1/4 会被头像/标题遮住，关键信息放**中间偏下**
- B站封面：右侧可能被时长角标遮，关键信息放**左侧**
- 小红书封面：主体居中，四周留白

## 5. 分平台格式

- 横版 16:9（1920×1080）→ B站 / 西瓜 / YouTube
- 竖版 9:16（1080×1920）→ 抖音 / 视频号 / 小红书

**竖版不是横版裁切**：要改 Remotion 的 `Config.setVideoImageFormat` 分辨率 + 场景布局重排（字幕位置、图表纵向堆叠）。Remotion 里用 `calculateMetadata` 或改 `Composition` 的 `width/height` 重渲。

时长建议：
- 抖音/视频号 ≤60s 流量好（长内容可拆成上中下三集，每集留钩子）
- B站 3–8 分钟可接受
- 小红书 竖版 30–60s

### 分发顺序

- **先发主平台，再重渲竖版发短视频平台**，错开发布时间（同一时间多平台发可能被判搬运）。
- 若主打短视频流量：先发抖音/视频号（拆短），B站同步发横版完整版。
- 若主打深度长视频：先发 B站 横版，攒口碑后重渲竖版发抖音导流。

### 发布通道（平台直发约定）

- **视频号 / 抖音 / 小红书**：无公开上传 API，人工在 App 内发布（本 skill 不自动化）。视频号若要经工具发，可用 `bilibili-publish` skill，但需有效 cookie，失效会停下来索要、不空转——别指望全自动。
- **B站**：用 `biliup` 直连上传（命令行 / CI 友好），横版完整版首选。
- 封面 / 标题 / 标签 / 简介仍按上面 §1–§4 准备好，发布前过 §8 checklist。
- **错开发布时间**：同一内容别多平台同一时刻发（可能被判搬运）；先发主平台，再重渲竖版发短视频平台。

## 6. 合规免责（红线）

- 视频画面 + 简介 + 评论区置顶，三处都要有「不构成投资建议」。
- **禁词清单**（标题/标签/简介/封面文字/口播画面都要避开）：
  - 荐股类：`荐股` `推荐买入` `必涨` `涨停` `翻倍` `稳赚` `保本` `内部消息` `庄家` `主力`
  - 诱导投资：`赶紧买` `错过后悔` `满仓` `梭哈` `跟买`
  - 承诺收益：`年化XX%` `稳赚不赔` `无风险`
  - 医疗类（内容涉医美/医疗时，注意医疗广告法）：`治疗` `疗效` `根治` `最安全`
- 个股名可以出现，但结论必须是「情景推演 / 概率分析」，不是「买它」。
- 引用数据要有出处（数据引用规则见全局记忆：标题/日期/来源/关键数据点/URL 五要素）。

## 8. 发布前检查清单（checklist，逐项过）

- [ ] 标题有钩子？前 15 字能看懂要说什么吗？
- [ ] 3 候选里挑了哪个，还是改了一版？
- [ ] 标签发前 WebSearch 验过平台真实热度吗？有没有自创词？
- [ ] 简介有免责声明吗？
- [ ] 封面数字和标题/简介/口播里的数字一致吗？
- [ ] 封面尺寸对不对（横 1280×720 / 竖 1080×1920）？关键信息在安全区内吗？
- [ ] 标题/标签/简介/封面扫过禁词清单吗？
- [ ] 竖版是重渲的，不是横版裁切吗？

## 9. 发布后复盘（决定下一支怎么改）

核心三指标：**封面点击率（CTR）、前 5 秒留存、完播率**。

| 症状 | 病根 | 下一支动作 |
|---|---|---|
| CTR 低 | 封面/标题不抓人 | 换封面视觉锤、换钩子 |
| 前 5 秒留存低 | 开头没钩住 | 钩子前置、删废话、开场直接抛结论/数字 |
| 完播率低 | 太长/节奏拖 | 砍时长、加速、拆短集 |
| 互动低（赞评比） | 结尾没引导 | 结尾加提问/投票引导 |
