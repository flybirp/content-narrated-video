# 分镜提炼方法论（结构由内容决定，不由模板决定）

这是本 skill 唯一需要"动脑"的一步，其余全是工程流水线。

## 分镜（beat）是什么

一个分镜 = **一个信息块** = 一句话口播 + 一个图表画面。

整支视频就是一条"分镜序列"：观众跟着口播，一镜一镜往下看，每镜消化一个信息块。

## 分镜怎么来：读内容 → 抓内在逻辑 → 切信息块

**不要套任何预设模板。** 源内容长什么样，分镜就长什么样。

源内容可以是任意形态：
- AI 对话记录（元宝 / ChatGPT / Claude / DeepSeek…）
- PPT / 演示文稿
- 一本书的一个章节 / 一篇文章
- 一份研报 / 数据报告 / 会议纪要

做法：
1. 通读源内容，先问一句「这段内容**内在**的逻辑结构是什么？」
2. 按这个逻辑，把内容切成一个个「能用一句话说清、能配一个画面」的信息块
3. 每个信息块就是一个分镜，给它的画面挑一种图表（见下）

## 每个分镜的判断标准（三条都要满足）

1. **一句话能说清** → 对应一句口播
2. **一个画面能表达** → 对应一个图表/动画
3. **和前后镜有逻辑递进** → 不是硬凑，是顺着内容往下走

不满足第 3 条的，说明切错了，要么合并、要么拆分。

## 图表选型：由信息形态决定（不是由模板决定）

| 信息形态 | 图表/画面 | 实例 |
|---|---|---|
| 多对象横向对比 | 柱状图 / 对照表 | 华熙 75x vs 爱美客 25.8x |
| 随时间变化 | 折线 / 面积 | 营收增速逐季走势 |
| 构成 / 占比 | 饼图 / 堆叠条 | 仓位四档分配 |
| 单个数字强调 | 大数字滚动动画 | 账上现金 65.7 亿 |
| 层级 / 步骤 | 堆叠卡片 / 流程 | 四档建仓递进 |
| 状态 / 进度 | 状态胶囊 / 进度条 | 催化剂「待兑现/进行中/已验证」 |
| 推演 / 场景 | 概率树 / 三列卡 | 悲观/中性/乐观三情景 |

**原则：画面要"同期显示口播正在说的那个数字"。** 口播说"二十五点八倍"，画面同一时刻就得出现 25.8x，不能口播讲 A、画面放 B。

## 例子（都是"一个例子"，不是模板）

**个股分析**（爱美客那期自然长出的结构）：
```
定调 → 为什么买(多头) → 风险(为什么不是买点) → 怎么买(仓位) → 预期收益 → 信号 → 收尾
```

**一本书的一章**可能是：
```
观点 → 论证1 → 论证2 → 反例 → 结论
```

**行业科普**可能是：
```
定义 → 现状 → 玩家格局 → 趋势 → 判断
```

**一份数据报告**可能是：
```
背景 → 三个发现 → 归因 → 建议
```

结构长什么样，取决于内容本身。skill 只负责"切分镜 → 配图表 → 出视频"这条流水线，不替你决定内容该怎么组织。
