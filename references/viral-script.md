# 病毒脚本原则（适配视频口播 + 标题 + 封面）

本文件把 `create-viral-content` 的社媒爆款方法论**适配到视频场景**：口播稿（= 视频脚本）怎么写钩子、怎么收尾、怎么躲 AI 味；标题与封面怎么按研究数据优化。配套 `SKILL.md` 的 Step 3 / Step 3.5 / 发布模块使用。

研究底座（40+ 来源，关键几条）：
- **BuzzSumo 1 亿标题研究**：标题最优长度 **11 词 / 65 字符**。
- **Outbrain**：负向超级词（"为什么你做错了"）比正向超级词 CTR **高 63%**。
- **Netflix**：用户 **82%** 浏览时间花在封面上，平均 **1.8 秒**做决策。
- **面孔心理学**：封面带人脸 CTR **+35~50%**（杏仁核激活）。
- **A/B 测试**：持续迭代 CTR 可随时间 **+30~40%**。

---

## §1 口播前 3 秒钩子（不给废话）

视频号 / 抖音 / 小红书等短视频，前 3 秒决定留存。开场直接抛钩子，删掉所有铺垫。

三种高转化钩子结构（任选其一，按内容选）：

| 结构 | 模板 | 例（财经/科技解说） |
|---|---|---|
| **预测 +  stakes** | `我认为 [概念] 是 [年份] 的 [品类]，会 [结果]。` | 「我认为算子优化是 2026 最被低估的技术活，它正在亲手埋掉写它的人。」 |
| **阵营分裂** | `[做法] 把 [赢家] 和 [其他人] 分开。` | 「这行把"真懂 GPU 的人"和"只会调 API 的人"彻底分开了。」 |
| **前-后压缩** | `过去要 [旧复杂度]，现在 [新简单]。` | 「过去调通一个算子要啃两周 PTX，现在一份脚本半天。」 |

短视频专属钩子（TikTok 验证）：
- **好奇**：`多数人不知道 [反常识事实]……`
- **问题**：`如果你被 [痛点] 折磨，看这个……`
- **结果**：`我把 [东西] 试了 [时长]，结果……`
- **争议**：`这就是为什么所有人都在 [话题] 上犯错……`

> 钩子要"带立场 / 带数字 / 带反常识"，不要"今天给大家讲讲"。

## §2 口播正文结构（镜像到分镜）

每个信息块按 **WHAT → HOW → WHY NOW → PAYOFF** 顺序，别先讲"为什么重要"再讲"是什么"：

1. **WHAT**：用 1–2 句说清概念（观众先懂是什么）。
2. **HOW**：给具体机制 + 例子（别只喊好处，要给可感知的动作）。
3. **WHY NOW**：为什么是现在 / 什么突破让它成立（时效性 = 分享理由）。
4. **PAYOFF**：观众能拿去用 / 能得出的结论。

反模式：开头先"它很重要"（空）、只有泛泛好处没机制、先卖 sizzle 再给 steak。

## §3 收尾：用命令，别用请求

结尾落在**权威感**，不落在示弱：

- ❌ 示弱 / 互动乞讨：`你觉得呢？` `评论区聊聊？` `喜欢点个赞~`
- ✅ 命令式收尾：`你的下一个 [动作] 不该 [老做法]，该 [新做法]。`
  - 例：`你下一只票的建仓计划，不该再靠感觉，该先算概率。」

> 短视频平台**鼓励互动**，可以留 CTA，但写成"具体邀请讨论 / 明确动作"，不是弱问句"你怎么看"。弱问句是 AI tell（见 §4）。例：把「你怎么看评论区聊聊」改成「这波你抄没抄？说说你的止损线」——有立场、有具体动作。

## §4 AI Tell 黑名单（口播 / 字幕 / 标题都要查）

杀掉这些一眼 AI 味的表达：

**过渡 tell**：`说白了` `接下来我们看` `这里有个关键点` `不过话说回来` → 直接陈述，不需要过渡。
**热情 tell**：`我很激动地分享` `这是一个颠覆性的` `革命性的` `堪称神器` → 让内容自己燃，不替观众激动。
**结构 tell**：`首先…其次…最后` 给每段编号硬套；`总而言之` `综上所述` → 用自然行文。
**互动乞讨 tell**：`你怎么看？` `评论区聊聊` `觉得有用点个赞` `改变我的想法` → 见 §3 改成命令/具体邀请。
**企业腔**：`赋能` ` leveraging` `落地解决方案` `抓手` → 用大白话动词：用、试、做、上。
**标点 tell（2024–2025）**：
- 破折号滥用 `——` 像这样 —— 到处都是（每 500 字最多 1 个）；
- 段首 `然而 / 此外 / 总的来说`；
- 赘词 `真实的事实` `最终结果` `密切 proximity`；
- 同义反复 `协作 together` `回退 back`；
- 句子长度全一样（都 15–18 字）—— 长短句交错。

**自检方法（朗读测试）**：把口播稿念出来，像不像跟朋友在酒吧聊？哪句别扭就改。

## §5 对抗式精修协议（Refinement Protocol，渲染前必跑）

口播稿写完后，攻它 5 轮，攻不动了再进 TTS / 渲染（省一轮 11 分钟渲染）：

| Pass | 角色 | 攻击点 |
|---|---|---|
| 1 怀疑者 | 普通观众 | `我为什么要关心？这有什么新东西？` |
| 2 专家 | 内行 | `技术准确吗？内行会挑哪根刺？` |
| 3 划走者 | 刷信息流 | `我会为这个停下来吗？钩子够不够？` |
| 4 竞品 | 同题材 10 条 | `和那 10 条比，差异点在哪？` |
| 5 编辑 | 砍字 | `删掉什么不影响意思？（病毒稿永远比草稿短 20%）` |

**放行阈值**：① 首句有好奇心或 stakes；② AI tell 零容忍（对照 §4 黑名单）；③ 平台字数达标（短视频口播单段 60–120 字）；④ 每个抽象结论 ≥1 个具体例子 / 数字；⑤ 收尾是命令不是请求。

## §6 标题病毒公式（发布层，配合 publish-guide §1）

在 publish-guide 已有钩子类型上，叠加研究规则：

- **最优长度 11 词 / 65 字符**（BuzzSumo）；竖版短视频前 15 字是钩子（抖音），钩子前置。
- **负向超级词 +63% CTR**：`[常见做法] 正在毁掉你的 [指标]` 比正向更抓。例：`三个习惯正在毁掉你的复购率` > `三个习惯提升复购率`。
- **具体数字碾压模糊**：`省下 1247 元` 胜 `省下 1000 元`；`跌 70%` 胜 `大跌`。
- **好奇心缺口**：`[群体] 不会告诉你的 [话题]`。
- **反常识 / 预测**：`[共识] 已死，接下来是 [新东西]`。
- 出 **≥3 候选**不同钩子方向（数字 / 悬念 / 反常识 / 身份 / 结果），按平台调性挑，不默认选数字版（见 publish-guide §4）。

## §7 封面病毒规则（发布层，配合 publish-guide §4 + gen_cover）

`gen_cover.py` 已支持 `--title / --metric / --sub / --accent`。叠加研究规则：

- **人脸 CTR +35~50%**：能放真人头像 / 表情图就用（短视频真人出镜头像见 SKILL.md「低配版真人出镜」）。
- **画面 ≤3 个元素**：「限制你的兰博基尼」——元素越多越不跳。
- **高对比配色**：深底 + 高亮强调色（财经涨红跌绿），暗色模式也要跳。
- **文字 3–4 词、粗无衬线**：封面只放钩子核心，完整句放标题栏（publish-guide §4 已强调）。
- **1.8 秒决策**：前 15 字（抖音）+ 封面必须一眼传达"这视频讲什么、凭什么看"。
- **移动端可读**：缩到 120px 宽仍能看清大字（真机/缩略图自检）。
- **标题协同不重复**：封面大字与视频标题互补，不照搬。
